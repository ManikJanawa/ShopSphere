# ShopSphere – Multi-Vendor E-Commerce Management System
ShopSphere is a **Java-based multi-vendor e-commerce application** developed to manage the complete flow of an online shopping system. It provides separate access for **Admin, Vendor, and Customer**, with database-driven management of products, orders, inventory, billing, and users.

## ✨ Key Features

* 👤 **Role-Based Access** – Separate functionality for Admin, Vendor, and Customer.
* 🛍️ **Product Management** – Add, update, search, and manage products.
* 👨‍💼 **Vendor Management** – Manage vendor details and vendor-related products.
* 👥 **Customer Management** – Store and manage customer information.
* 🛒 **Shopping & Checkout** – Add products to cart and place orders.
* 📦 **Order Management** – Create and manage customer orders and order items.
* 📊 **Inventory Management** – Track product stock and update inventory after purchases.
* 💳 **Billing Management** – Generate and manage billing information.
* 🚚 **Order Status Tracking** – Manage the order status throughout the order process.
* 🔐 **Database Connectivity** – Store and manage application data using MySQL and JDBC.
* 💵 **Cash on Delivery** – Supports COD-based order processing.

## 🛠️ Tech Stack

* **Java** – Core application development
* **Java Swing** – User interface
* **MySQL** – Database management
* **JDBC** – Database connectivity
* **SQL** – Data storage and operations
